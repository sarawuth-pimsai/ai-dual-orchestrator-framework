# Fictional sample project: appointment reminders

Initialize this directory using the CLI and a verified framework pin as described in the root README. This sample has no approved implementation or release.

- Business: read `.ai-framework/framework/roles/BUSINESS_ORCHESTRATOR.md`; receive the Requirements role's handoff and provide user consent and UX input. Ask Founder for business decisions.
- Requirements: read `.ai-framework/framework/roles/REQUIREMENTS.md`; keep the product contract, propose the risk tier, write and run e2e scripts.
- Implementation: read `.ai-framework/framework/roles/IMPLEMENTATION.md`; propose technical choices, write code and unit/integration tests. Implementation needs explicit Founder approval.
- PM: read `.ai-framework/framework/roles/PM_AGENT.md`; reconcile the plans and report dependencies without directing any peer.

Use the project's documents and code repositories and their actual decisions and issues as project source of truth. Handoffs await a real receiver acknowledgment.
